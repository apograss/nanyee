Token 获取教程

两种方式获取群报数登录凭证，选择适合你的方案

? 什么是 Token？

简单说

Token 是你在群报数小程序的"登录凭证"。我们需要它来代替你自动完成打卡。就像你给了一把钥匙，让工具帮你开门签到。

i Token 有效期约 7 天，过期后重新获取即可。你的微信账号完全安全，Token 仅用于打卡接口。
! 选择获取方式
一键工具（推荐）
手动抓包
! 推荐方式！双击运行，自动获取 Token 并复制到剪贴板，全程不到 1 分钟。

前置条件

• Windows 电脑
• 安装了 Python 3.8+（安装时勾选 "Add to PATH"）
• PC 端微信已登录

0

下载并安装环境 （仅首次）

下载工具包后，先运行 setup.bat 安装 mitmproxy 和证书。

下载 Token 获取工具
// 解压后文件结构
token_tool/
+-- setup.bat ← 首次运行这个
+-- get_token.bat ← 日常运行这个
+-- capture_token.py ← 自动调用
1

运行获取工具

双击 get_token.bat，看到提示界面说明工具已就绪。

2

打开群报数小程序

在 PC 微信 中打开群报数小程序，随便点进一个打卡活动即可。

! 必须用 PC 端微信打开小程序，手机微信无法抓包。
3

Token 自动捕获

工具会自动检测到 Token 并复制到剪贴板：

! Token 已在剪贴板！直接回到打卡助手的「设置」页面粘贴即可。
i 如果一键工具无法使用，可以手动配置 mitmproxy 抓包。需要一定技术基础。
1

安装 mitmproxy

pip install mitmproxy

安装后运行一次 mitmdump 生成 CA 证书，然后安装证书：

# 安装 CA 证书到系统
certutil -addstore -user root %USERPROFILE%\.mitmproxy\mitmproxy-ca-cert.cer
2

启动抓包代理

mitmdump -p 8899 --ssl-insecure -q --set flow_detail=1

然后在 Windows 设置 → 网络 → 代理 → 手动代理 中设置：

地址: 127.0.0.1
端口: 8899
3

打开小程序并找到 Token

在 PC 微信打开群报数小程序。在 mitmdump 输出中找到发往 form.qun100.com 的请求。

找到请求头中的 Authorization 字段，复制该值即为 Token。

# 输出示例
GET https://form.qun100.com/v2/activity/list
  Authorization: 2XEMO6kICDthQHYxo5mMXjCH...
4

还原代理设置

获取完成后，务必关闭系统代理：

Windows 设置 → 网络 → 代理 → 关闭"手动代理"

! 忘记关闭代理会导致网络无法正常使用！
? 常见问题
Token 会泄露我的微信信息吗？ ↓
不会。Token 只是群报数小程序的会话凭证，只能用于群报数的打卡接口，无法访问你的微信聊天、通讯录等任何隐私信息。
Token 多久过期？ ↓
大约 7 天。过期后打卡会失败，重新运行工具获取新 Token 即可。
工具提示"未检测到 mitmdump"怎么办？ ↓
请先运行 setup.bat 安装环境。如果仍然失败，确认 Python 已正确安装并添加到 PATH 环境变量中。
运行工具后网络不能用了？ ↓
工具正常结束会自动还原代理设置。如果异常退出，请手动关闭：Windows 设置 → 网络和 Internet → 代理 → 关闭"使用代理服务器"。
Mac / Linux 能用吗？ ↓
目前一键工具仅支持 Windows。Mac/Linux 用户请参照"手动抓包"方式操作。
