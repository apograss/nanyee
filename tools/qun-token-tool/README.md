# 群报数 Token 获取工具（Windows）

这个工具用于从 PC 微信里的群报数小程序获取 `Authorization Token`，方便粘贴到 Nanyee 的群报数页面。Token 只会复制到 Windows 剪贴板，不会写入磁盘，也不会被这个工具上传到其他服务器。

## 首次使用

1. 安装 Python 3.12 或更高版本，并在安装界面勾选将 Python 加入 `PATH`。
2. 双击 `setup.bat`。它会安装 `mitmproxy`，并把 mitmproxy 根证书安装到**当前 Windows 用户**的受信任根证书存储。
3. 安装成功后关闭窗口。

## 获取 Token

1. 完全退出 PC 微信，再重新打开并登录。
2. 双击 `get_token.bat`，保持命令窗口开启。
3. 在 PC 微信中打开群报数小程序，进入任意一个表单。
4. 窗口提示成功后，Token 已在剪贴板中，回到网站直接粘贴即可。

脚本会临时把 Windows 系统代理改为 `127.0.0.1:8899`，成功、报错或按 `Ctrl+C` 取消时都会恢复原设置。如果电脑被强制关机导致代理没有恢复，请到 Windows“设置 → 网络和 Internet → 代理”中关闭手动代理。

## 安全说明

- 只从 `qun100.com` 及其子域读取 `Authorization` 请求头，不记录网页内容。
- 使用完成后工具不会继续运行，系统代理也会恢复。
- Token 等同于登录凭证，不要发给他人，不要粘贴到群聊或教程截图中。
- mitmproxy 根证书使该工具能读取代理期间的 HTTPS 请求。若以后不再使用，可在 `certmgr.msc` 的“受信任的根证书颁发机构 → 证书”中删除名称含 `mitmproxy` 的证书。
- Token 的有效期由群报数实际会话决定；失效后重新获取即可。
