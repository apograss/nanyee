# 术语表

| 术语 | 含义 |
|---|---|
| 平台账号 | 南医工具台（nanyee.de）上的用户账号，用户名 + 平台密码，对应 `users` 表。与学校账号无关。 |
| 学校账号 / 学号 | 学校统一身份认证（`uis.smu.edu.cn`）的账号，自动评课、学习舱用它登录学校系统。 |
| 统一身份认证密码 | 学校账号在 `uis.smu.edu.cn` 的密码，本站登录学校时用的就是它。与教务系统（`zhjw`）自己的密码不同，改后者对本站无效。 |
| 学校凭据 | 用户托管在本站的学校账号 + 统一身份认证密码，加密存于 `hosted_credentials`，用途为 `school` / `evaluation` / `study_cabin`。 |
| 自动评课任务 | `tool_id = evaluation` 的长期任务，每晚北京时间 21:10–23:30 随机运行一次，默认持续 180 天。挂在创建它的平台账号下。 |
| 旧账号 / 孤儿任务 | 用户忘记平台密码后弃用的平台账号，以及其上仍在运行、用户自己无法取消的评课任务。 |
| 学号摘要（`account_digest`） | 学校凭据中学号的 HMAC 盲索引，用于在不解密的前提下判断两条凭据是否为同一学号。见 [ADR 0002](adr/0002-school-account-conflict-takeover.md)。 |
| 检查并停止 | 用户用自己的学校凭据实时登录学校成功后，停止其他平台账号上同一学号的自动评课任务。见 [ADR 0002](adr/0002-school-account-conflict-takeover.md)。 |
| 绑定邮箱 | 平台账号关联的、经验证码验证的邮箱，用于找回平台密码。一个邮箱只能绑一个账号。见 [ADR 0001](adr/0001-account-email-binding-and-password-reset.md)。 |
